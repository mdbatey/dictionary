# Reference: sentence switchboards & breakdowns

Copies of earlier Claude artifacts, kept here for reference and inspiration.
Every `.html` file is a single self-contained page with no build step. Open one in a browser to use it.

## Sentence switchboards

Pages built around one sentence. You flip switches (person, tense, politeness, negation, …) and only the parts of the sentence that change get updated.

A set of sentences, each split into color-coded pieces you can tap. Each piece is stacked in three layers: a literal gloss, the original script, and the pronunciation.
