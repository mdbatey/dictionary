# Dictionary Layers

A GitHub Pages site (repo: `dictionary`, live at mdbatey.github.io/dictionary) for language study: sentence switchboards, sentence breakdowns and flashcards, built from data stored in this repo. Earlier one-off pages are kept in `reference/` for inspiration.

## Working agreements

- **One branch and one pull request per ticket.** The owner reviews and merges. Never commit ticket work directly to `main`, because every push to `main` publishes the live site. The PR body says `Closes #N` for its ticket.
- **The roadmap is in `docs/plan/`.** v1's tickets are GitHub issues #2–#13, sub-issues of the spec, #1.

## Agent skills

### Issue tracker

Specs and tickets are GitHub Issues on mdbatey/dictionary. See `docs/agents/issue-tracker.md`.
